## 5. Cost

Cost is computed as:

```
cost_per_1M_tokens = (gpu_hourly_usd × wall_clock_hours) ÷ tokens_generated × 1e6
```

against the public reference price declared in `configs/cost.yaml`. The benchmark GPU is a lab
machine with no invoice, so this is an assumption and is stated as one.

**On price sensitivity.** Every configuration in this sweep runs on the same GPU, so the hourly
rate enters as a linear scalar and **the ranking of configurations is invariant to GPU price**.
There is no crossover rate at which a different configuration wins, and a price-sensitivity
table would imply a result that does not exist.

What *does* reorder the frontier is the **latency SLA**: a p95 TTFT budget determines which
configurations are admissible and at what request rate, which changes sustainable throughput and
therefore cost per token. That analysis is presented in §4 in place of a price table.
